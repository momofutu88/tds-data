# 复制带单引擎 v0.1（自建带单号）

> 2026-11-11 22:00 · 代码已入库并自检通过；当前跑 dry-run，未接真钱。

## 1. 一句话

不再把钱交给带单员去"跟"，而是把他们的**开仓信号**读出来，按定比折算后下到自己的账户里，**止盈止损由我们自己写死在代码里**——这样法兰西那种"2 分钟从 +38% 到 −171U"的窗口就不存在了，因为平仓不需要人。

## 2. 能解决什么 / 不能解决什么

| 解决的问题 | 怎么解决 |
|---|---|
| 止盈靠人、来不及 | 账户级止盈写进引擎，净利 ≥20% 立即全平，零延迟 |
| 单一带单员黑箱（法兰西 15x 单仓） | 多源聚合，单源熔断 20%，一个源坏了不影响整体 |
| 带单员改策略你后知后觉 | 引擎读的是真实仓位，不是他的简介 |
| 分润 10~13% | 自己带单，不付分润 |
| 提现要抢时间 | 止盈后仓位已平，提现变成"有空点一下" |

| 不能解决的 | 说明 |
|---|---|
| 资金门槛 | 开带单组合需约 **1,000U** 保证金，现在钱不够（见第 5 节） |
| 复制损耗 | 轮询延迟 10~60 秒，入场价永远比源差一点。影子引擎正在量化，两周后出数 |
| 代码风险 | 方向写反、数量算错，亏得比跟单更快。所以必须先 dry-run 两周 |
| 运维 | 必须 7×24 常驻环境（VPS），Actions 5 分钟一跑等于半山腰接单 |
| 带单号规则 | 带单员不能跟自己的号；带单号的止盈/止损只能靠引擎，平台不给按钮 |

## 3. 架构（已实现）

```
信号层  ── 轮询源仓位 position-history（10s）
   │      定比折算：目标名义 = 源仓位名义 × (分配资金 / 源权益)
决策层  ── 差分：目标 vs 实际 → 开/平仓指令（<2% 本金的差异忽略）
风控层  ── 账户止盈 20% / 单源熔断 20% / 单标的 35% / 并发 8 笔 / 滑点 0.8% 放弃
执行层  ── 市价单（reduceOnly 平仓），live 需 BINANCE_KEY + ALLOW_LIVE=1 双开关
审计层  ── data/engine_journal.jsonl 逐笔记账 + state/engine_state.json 持仓快照
```

代码：`scripts/copy_engine.py`（约 380 行，含自检）
工作流：`.github/workflows/engine_dry.yml`（每 30 分钟跑一轮纸面账户）

## 5. 风控参数（改代码里的 CONFIG，不靠人记）

| 参数 | 值 | 含义 |
|---|---|---|
| capital | 1000U | 带单号本金 |
| tp_pct | 20% | 净利 200U 全平停引擎（对应你要的 20% 止盈） |
| per_source_dd | 20% | 某源亏掉其分配额 20% → 永久停用该源（一票否决） |
| max_positions | 8 | 最多同时 8 笔 |
| max_symbol_pct | 35% | 单标的占用本金不超 350U |
| max_slip | 0.8% | 吃单价偏离源成交价超 0.8% 就放弃该笔 |
| poll_sec | 10 | 轮询间隔 |

## 7. 三个阶段（别跳步）

**阶段一：纸面（现在 → 11-25）**
`engine_dry.yml` 每 30 分钟跑，纸面账户 1,000U，多源（爽翻天 + 甜蜜蜜）。看三件事：折算后的单笔规模是否合理、信号延迟多久、纸面权益曲线跟源差多少。

**阶段二：小资金实盘（12 月中，VPS 到位后）**
500U 起，只接一个源（甜蜜蜜，因为它的单笔风险只有 0.3%），`--mode live --loop`。跑两周，对比纸面与实际成交价的差异。这一步是验证"代码有没有 bug"的，不是验证策略。

**阶段三：聚合（稳定后）**
1,000U，多源加权，带单号对外。此阶段可以把自己现有的跟单撤掉，资金并进引擎，账户数从 5 个降到 1 个。

## 8. 已知风险（按严重度）

1. **代码 bug** → 方向反了就是反向跟单。对策：dry 两周 + 500U 小资金两周，两轮都过才上 1,000U。
2. **API Key 泄露** → 只能开合约交易、绑 IP、不开提现，且 Key 只存 VPS 环境变量（不进仓库、不进对话）。
3. **VPS 掉线** → 仓位还在、引擎停了，等于裸奔。对策：心跳监控（5 分钟没心跳推 ntfy）+ 交易所侧止损单兜底。
4. **交易所限频** → 10 秒一次轮询 + 下单，远低于限额，但要注意并发源多时加延时。
5. **复制损耗** → 影子引擎正在量化。若两周后显示延迟 30s 的入场劣化中位 > 单笔利润的 1/3，就不该做。
